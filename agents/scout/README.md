# LAZARUS Scout
Differential tester for software ports. It mutates recorded requests with edge cases such as stray whitespace, boundary numbers and missing fields, sends each to the original and the port, and reports every difference with the input that reproduces it.

It watches for newly adopted versions and tests them unprompted. A difference it finds can go straight into the LAZARUS improvement loop. Say `scout` to run it now.
