# LAZARUS Sentinel
Release control for AI-generated Python. Paste code and it blocks anything that starts other programs, calls the network, reads secrets, or goes looking for test answers. It parses the code and never runs it.

In LAZARUS, every generated port passes through Sentinel first. A blocked version is rolled back and never reaches the behaviour gate.
