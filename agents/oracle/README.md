# LAZARUS Oracle
Deterministic, independent behavioral-equivalence oracle for software archaeology, behavioral equivalence and bug bounty work.
Say `Hunt <request JSON>` or `Hunt: <plain English>`. Stake 1 testnet FET. If the resurrected port and the original binary disagree on your input, you get your stake back plus 5 FET.
